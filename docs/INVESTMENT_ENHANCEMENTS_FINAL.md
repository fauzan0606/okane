# Investment Enhancements

Implemented on `feat/investment-enhancements-local`.

## Changes
- Allow SELL at price 0 for worthless/bankrupt positions.
- Add Dividend recording using the existing DIVIDEND investment transaction type and settlement to RDN.
- Add Asset Summary Cards/Table selector with browser persistence.
- Sort Asset Summary alphabetically by ticker/name.
- Preserve existing Realized P/L, Refresh Prices, Sell All, and existing investment layout.

## Local rollout
Pull this branch, then run TypeScript checks and the local development server before merging into the main phase-2 branch.
